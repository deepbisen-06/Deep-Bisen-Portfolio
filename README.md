## 🧭 Overview

Welcome to the official personal portfolio website of **Deep Bisen**, an undergraduate pursuing **B.Tech in Robotics & Artificial Intelligence** at Priyadarshini College of Engineering, Nagpur.

Designed with an editorial lavender dark aesthetic, this portfolio showcases projects ranging from real-time Conversational Voice AI and Applied Machine Learning to physical hardware prototypes, microcontrollers, and interactive web experiences.

### ✨ Highlights & Design Philosophy
- **Modern Lavender & Obsidian Aesthetic**: Clean editorial typography using Google Fonts (*DM Sans* & *Space Grotesk*), dark obsidian gradients, and soft lavender accents.
- **Micro-Interactions & Fluid Motion**: Dynamic pointer tracking, tilt physics on the portrait stage, and smooth scroll reveal animations powered by lightweight vanilla JavaScript (`motion.js`).
- **Zero-Dependency Architecture**: Built cleanly with semantic HTML5 and vanilla CSS3—no heavy frameworks, complex build steps, or bundle overhead.
- **Fully Responsive**: Optimized fluid grid layouts for mobile, tablet, and ultra-wide screens.

## 💻 Running the Project Locally

No build step, node modules, or environment variables are needed to preview this project.

### Option 1: Direct Browser Launch
Simply double-click `index.html` or drag and drop it into any modern web browser (Chrome, Edge, Firefox, Safari).

### Option 2: Python Local HTTP Server
Run a lightweight server from the project directory:

```bash
# Start local server
python -m http.server 8000
```
Then navigate to `http://localhost:8000` in your web browser.

### Option 3: Node / NPX
```bash
npx serve .
```

## 🌐 Deployment (GitHub Pages)

To publish this portfolio to GitHub Pages:
1. Go to repository **Settings** > **Pages**.
2. Under **Build and deployment**, set **Source** to `Deploy from a branch`.
3. Select `main` branch and `/ (root)` folder.
4. Click **Save**. Your site will be live at `https://deepbisen-06.github.io/Deep-Bisen-Portfolio/`.
